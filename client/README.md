# Kawika client

React + TypeScript single-page app for Kawika, built with Vite.

```bash
npm install
npm run dev          # http://localhost:5173 (proxies /api to :8000)
npm test             # unit tests
npm run test:e2e     # end-to-end UAT suite
```
